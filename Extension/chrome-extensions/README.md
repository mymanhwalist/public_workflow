# Job Board Chrome Extensions

All working Chrome extensions for job board scraping in one place.

## 📁 Extensions

### 1. wellfound-extension
**Purpose:** Scrape company data from Wellfound.com (formerly AngelList)

**Features:**
- Extracts company name, website, career page from Wellfound listings
- Auto-syncs to Supabase database
- Stores HTML inspection data for future scraper development
- 4,013 unique companies collected

**Database:** Supabase (career_pages table)

**Load in Chrome:**
```
chrome://extensions/ → Load unpacked → Select "wellfound-extension" folder
```

---

### 2. hiring-cafe-extension
**Purpose:** Scrape job listings from HiringCafe.com

**Features:**
- Extracts job postings with detailed information
- Content extraction for job details
- Options page for configuration
- Advanced popup UI with data display

**Load in Chrome:**
```
chrome://extensions/ → Load unpacked → Select "hiring-cafe-extension" folder
```

---

## 🚀 Quick Start

1. Open Chrome: `chrome://extensions/`
2. Enable "Developer mode" (top right)
3. Click "Load unpacked"
4. Select the extension folder you want to use
